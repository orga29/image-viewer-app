# 🖼️ Picasa Clone Viewer (PyQt6)

Windows 11環境で動作する、軽量・高速なPicasa風フルスクリーン画像ビューアアプリケーションです。  
矢印キーによるスムーズな画像連続遷移、マウスホイールによるカーソル位置中心の直感的なズーム＆パン操作、画像ごとの独立したズーム記憶機能を提供します。

---

## ✨ 主な特徴

- 🚀 **フルスクリーン・超軽量表示**: 余計なフレームやツールバーを一切廃した黒背景の高速画像ビューア。
- 🔍 **画像ごとの独立したズーム＆座標記憶**: 各画像ごとに指定した拡大倍率と表示座標を独立して記憶・自動復元。
- 🖼️ **ドラッグ＆ドロップ待機画面**: 起動時に勝手にダイアログが開かず、画像をドラッグ＆ドロップするだけで同一フォルダ内の全画像を自動リスト化して即座に閲覧開始。
- 📊 **ズーム倍率リアルタイム通知**: マウスホイールや矢印キーで倍率を変更した際、画面左下に現在の拡大率（例: `150%`, `100% (Fit)`）を一時オーバーレイ表示。
- ⌨️ **キーボード操作最優先**: 拡大表示中であっても矢印キーで確実に隣のファイルへ遷移。

---

## ⌨️ キーボード・マウス操作ガイド

| 操作 | アクション |
| :--- | :--- |
| **`→` (右矢印)** / **`Space`** / **`PageDown`** | 次の画像へ移動 (末尾で停止) |
| **`←` (左矢印)** / **`PageUp`** / **`Backspace`** | 前の画像へ移動 (先頭で停止) |
| **`↑` (上矢印)** | ズームイン（拡大表示 / 最大500%上限） |
| **`↓` (下矢印)** | ズームアウト（縮小表示） |
| **`F5`** / **`R`** / **`0`** | 現在の画像のズーム記憶をリセットしフィット表示 |
| **`O`** | ファイル / フォルダを開くダイアログを表示 |
| **`F11`** | フルスクリーン / ウィンドウ表示の切り替え |
| **`Esc`** / **`Alt + F4`** | アプリの終了 (フルスクリーン時は解除) |
| **マウスホイール** | マウスカーソル位置を中心に拡大 / 縮小 |
| **左ドラッグ** | 画像のパン（位置移動） |
| **ドラッグ＆ドロップ** | 画像ファイルを画面にドロップして開く |

## 🚀 動作環境・起動手順

### 必要要件
- Python 3.10+
- PyQt6 >= 6.5.0
- Pillow >= 10.0.0

### インストールと起動

```bash
# 1. リポジトリのクローン
git clone https://github.com/orga29/image-viewer-app.git
cd image-viewer-app

# 2. 依存パッケージのインストール
pip install -r requirements.txt

# 3. アプリの起動
python main.py
```

### Windows 11 用ビルド (.exe)
`pyinstaller` を使用して独立型 Windows 実行ファイルをビルドできます：

```bash
pip install pyinstaller
pyinstaller --noconsole --name "PicasaViewer" --clean -y main.py
```
