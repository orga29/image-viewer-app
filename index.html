Picasa風 Fast Image Viewer の主な特徴

直感的な操作性と、ストレスを感じさせない圧倒的な高速レスポンスを追求しました。

🚀

フルスクリーン・超軽量表示

ボタンや余分なフレームを排除した黒背景空間。アプリ起動と同時に一瞬で全画面表示され、写真そのものに集中できます。

🔍

画像ごとの独立ズーム＆座標記憶

各画像ごとに指定した拡大倍率と表示位置を個別に記憶。矢印キーで前後の画像へ移動しても、拡大した位置をそのまま復元・維持します。

🖱️

右クリックコンテキストメニュー

画面上のどこを右クリックしても洗練されたメニューがポップアップ。「ファイルを開く」「ズームリセット」「全画面切替」「終了」がスムーズに行えます。

🖥️

マルチモニター完全対応

サブモニターで表示中にフルスクリーン表示や解除（F11/Esc）を行っても、メイン画面に移動せずサブモニター上で表示が完全維持されます。

🖼️

ドラッグ＆ドロップ待機画面

起動時にダイアログが勝手に開かず、画像をドロップするだけで同一フォルダ内の全画像を自動検出・リスト化して即座に連続閲覧が可能。

📊

リアルタイム倍率オーバーレイ

マウスホイールや上下矢印キーでズームを変更すると、画面左下に `150%` や `100% (Fit)` と現在の拡大率が数秒間ポップアップ表示されます。

キーボード・マウス操作ガイド

キーボード主体の操作で、素早い画像チェックが可能です。

入力方法 割り当てキー / アクション 動作
キーボード → / Space / PageDown 次の画像へ移動 (末尾で固定停止)
キーボード ← / Backspace / PageUp 前の画像へ移動 (先頭で固定停止)
キーボード ↑ (上矢印) ズームイン (拡大表示 / 最大465%上限)
キーボード ↓ (下矢印) ズームアウト (縮小表示)
キーボード F5 / R / 0 ズームと位置をリセット (フィット表示)
キーボード F11 フルスクリーン / ウィンドウ表示の切り替え (配置モニター位置維持)
キーボード Esc / Alt + F4 アプリの終了 (フルスクリーン時は解除)
マウス 右クリック コンテキストメニュー表示 (ファイル選択/リセット/全画面/終了)
マウス マウスホイール回転 カーソル位置を中心に拡大 / 縮小
マウス 左ドラッグ 画像内を自由自在にパン (移動)
マウス ドラッグ＆ドロップ 画像ファイルをウィンドウ上にドロップして即時表示
